Quick Reference

scraper() must return an array of image URL strings.

Common selectors:

img[src] — basic images

img[data-src] — lazy-loaded

img[data-zoom-image] — zoom galleries

a[href$=".jpg"] — direct image links

Filter pattern:

/icon|logo|sprite|thumb/i.test(url)

Shopify product API:

/products/[handle].js
